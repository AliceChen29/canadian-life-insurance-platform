# canadian-life-insurance-platform
Educational life insurance analytics platform: coverage needs calculator, risk scoring, illustrative premium estimation, and product recommendation.
🔗 **[Live Demo](https://canadian-life-insurance-platform-j8tladavzd6mxlnrjj4ey2.streamlit.app)**

## Disclaimer
⚠️ This is an educational student project. All figures are illustrative estimates and do NOT constitute real insurance quotes or professional advice. Please consult a licensed insurance advisor before making any decisions.

## Features
- Insurance needs calculator (income replacement method)
- Product recommendation engine (Term 10/20/30, Permanent Life)
- Risk scoring model
- Illustrative premium estimation
- Statistical analysis using R (EDA + Gamma GLM)

## Tech Stack
Python, Streamlit, R

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Limitations
- Uses simplified assumptions, not real actuarial mortality tables
- Synthetic data used for statistical analysis
- Not a substitute for professional insurance advice
