在RStudio里,点 File → New File → R Script,保存到 analysis/eda.R。

r
library(tidyverse)

# Read the synthetic data
data <- read_csv("data/raw/synthetic_applicants.csv")

# Quick look at the data
glimpse(data)
summary(data)

# Distribution of age
ggplot(data, aes(x = age)) +
  geom_histogram(binwidth = 5, fill = "steelblue", color = "white") +
  labs(title = "Age Distribution of Applicants", x = "Age", y = "Count")

# Distribution of annual premium
ggplot(data, aes(x = annual_premium)) +
  geom_histogram(bins = 40, fill = "darkorange", color = "white") +
  labs(title = "Distribution of Estimated Annual Premium", x = "Annual Premium ($)", y = "Count")

# Premium by smoking status
ggplot(data, aes(x = factor(smoker), y = annual_premium)) +
  geom_boxplot(fill = "lightgreen") +
  labs(title = "Premium by Smoking Status", x = "Smoker (0 = No, 1 = Yes)", y = "Annual Premium ($)")

# Premium vs age, colored by smoking status
ggplot(data, aes(x = age, y = annual_premium, color = factor(smoker))) +
  geom_point(alpha = 0.4) +
  labs(title = "Premium vs Age by Smoking Status", x = "Age", y = "Annual Premium ($)", color = "Smoker")

明白了,你用的是学校的 RStudio Server(网页版RStudio,通过 r.datatools.utoronto.ca 访问),不是你自己电脑上安装的RStudio桌面版。这个情况需要注意几个关键点。

关键问题:学校服务器访问不到你电脑本地的文件

你的项目文件夹 canadian-life-insurance-platform 现在存在你自己电脑的Desktop上,但这个RStudio Server运行在多伦多大学的服务器上,它默认只能看到服务器上的Home目录(就是你现在Files面板里看到的那些文件,比如in_class_activity_2这些)。

它看不到你电脑本地的文件,所以直接用 setwd("~/Desktop/...") 会报错,因为服务器上根本没有这个路径。

解决方法:把CSV文件上传到RStudio Server

第1步:找到你的CSV文件

回到VS Code,在左边EXPLORER里找到 data/raw/synthetic_applicants.csv

第2步:上传到RStudio Server

回到RStudio Server网页,在右下角 Files 面板:

  1. 点 Home,创建一个新文件夹方便整理(可选):点上方那个"新建文件夹"图标,命名为 insurance-project
  2. 进入这个文件夹后,点 Upload 按钮(在Files面板工具栏,通常是一个上传图标)
  3. 选择你电脑上的 synthetic_applicants.csv 文件,上传

第3步:确认路径后读取数据

上传完成后,在Console里运行:

r
getwd()
list.files()

确认csv文件出现在列表里,然后:

r
library(tidyverse)
data <- read_csv("synthetic_applicants.csv")
glimpse(data)
